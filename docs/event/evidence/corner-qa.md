# 双人创作角：规则与候选验收

进入路径：双向朋友的人物卡「邀请共同创作」；本人入口「我的创作与邀请」。对方必须本人明确参与，发起者不能代替。列表显示最近 50 份记录。

各人只编辑自己的部分，署名与小人取自本人已保存的身份；照片只能选本人当前可用的原件。明确提交后，所选私藏照片可由这一位参与者在该创作角读取，不会因此公开到现场、进入照片交换或扩大普通照片接口权限。

同一版本需双方分别确认，保存也是各人的独立选择。编辑会让旧确认、保存版本的在线导出资格失效。PNG 需另行选择导出，生成前后及下载前复核当前关系、素材和版本，显示实际成品。长留言扩展画布，保留全文与作者署名。主动下载的文件无法远程收回。

撤回、删除或修改素材时，作者必须重新选择；屏蔽再解除、移除朋友再添加不会复活旧创作权限。任一参与者可以撤销共同创作。旧保存标记保留，但不能绕过现有许可重新读取原件。

断网、失败、取消、刷新、多标签与重复操作通过原请求日志和版本校验处理。未提交草稿与待确认请求按本人身份隔离；恢复连接不自动发送，用户明确重试原请求。关闭窗口终止等待和预览，不能承诺撤销已在服务提交的操作。

候选全量 699 项测试通过，包括 Node/Worker 权限、事务、并发冲突、独立保存、持久化、素材撤回、暂时屏蔽与在途响应复核。15 步双身份浏览器闭环通过：明确交友及参与、私藏照片定向读取、双向确认、独立保存、实际 PNG 下载、刷新、多标签、断网原请求、关闭后恢复、重启、删除原件及撤销共同创作；无页面异常。390×844 与 320×568 检查通过，长留言实际 PNG 为 1200×1920。五项构建、AI 文件及角色结构检查通过。实际发行包结果将在完成后登记。

合成测试身份不是目标用户研究；手机尺寸检查不是实体手机验收。未新增素材、外部服务或公开私人数据。
