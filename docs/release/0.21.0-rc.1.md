# Music Space 0.21.0-rc.1 · 原版 Music Map 整合预发布

Music Map 的完整原版三维页面进入同一应用，保留小院、唱片桌、翻片寻声、自由探索和「我的发现」。从现场或聊天室进入，返回恢复机位与未发送草稿；核对过的录音只准备聊天或接龙草稿，发送与开局仍须本人确认。

完整页面往返释放前一个 WebGL 场景，共用同源缓存的 Three 模块。Space 使用独立存储键，不修改独立 Map、旧 Pages 或私人照片权限。手机返回入口与作品动作已按实际短屏检查调整；无 WebGL 使用原版二维降级，断网留在当前页并允许重试。

这是本地服务预发布候选，不是正式生产上线。真实手机、真实观众与低端 GPU 仍需验证。迁移及验收边界见 `docs/event/evidence/original-map-qa.md`。
