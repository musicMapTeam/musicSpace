仍阻断：

测试在运行中以另一份合法合成会话替换当前storage，再触发storage/online/focus，旧身份仍持续显示并回写。旧正文/草稿/重试保留，必须修复实时存储协调与迟到响应。这不是已证明“用C凭据读到A历史”：实际窗口仍标识并鉴权为A；正确C重新加载已经隔离通过。

修复方向：每浏览器origin共享一个匿名身份，不新增多账户切换按钮。外部凭据变化时立即清私密视图并使旧控制器失去写回能力，随后重新加载核验新会话；同凭据正常重连仍保留对话。旧待确认请求保留给原身份核对，不转发给新身份，也不假称已撤回。下一候选仅复验此边界与本地启动器。

其他未验项保持原范围：实体手机、真实OS后台切换、生产负载、全部装扮组合、运营举报/账号恢复。网络故障/403或404为刻意测试日志，不能称整个console毫无错误。
