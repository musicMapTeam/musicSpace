# Music Space 实施说明 · 文档 3.1

2026-10-04 本轮补充：应用内 Music Map 改用独立 Map 0.16.0 的完整原版页面与真实三维唱片桌，保留小院、翻片寻声、自由探索、来源署名和「我的发现」。入口 `/music-map/`，从现场或聊天室进入；全页往返只运行一个 Three 渲染器，共用同源版本化 Three 模块。Space 独立存储，恢复原聊天室、未发送草稿与机位；37 条已核对录音可以准备分享或接龙草稿，仍须本人明确确认并由服务复核资格。开放目录署名不当成共同演唱，也不进入这些草稿。独立 Map、旧 Pages 和生产部署不变。

2026-10-03 最新授权：将已认可的刊物夜场样张落地到真实三维场馆，并把 Music Map 的音乐关系探索整合进同一应用。独立 Map 正常保留，旧的产品分拆约束不再限制本轮明确授权的复用。使用其 c626c0e54de1f5ea362710f1e47bacd8c09aa804 留档目录：29 位真实音乐人、37 条共同演唱录音关系；显示版本、署名、出处和核对日期，不捏造合作，也不新增音频服务。应用内选择节点、查看关系、回退与找目录内路径；分享和接龙只准备草稿，仍须本人明确确认，权限由既有聊天室和小游戏服务执行。暖纸、深绿、木色与二维角色共同构图；聊天消息独立滚动、输入常驻，手机优先保证读写。二维样张舞台不是三维实现证据。

2026-10-03 第三阶段：成员音乐话题可发布、署名、撤回并明确带回讨论；Worldcup 支持四个自填文字选项、真实票数、明确平票理由、历史结果与讨论。新增自愿「音乐默契局」和轮流「关系接龙」：至少两人明确参加，选择揭晓前保密，接龙区分已核实共同音乐人与成员自述。没有评分、自动好友或自动邀请；退出清理未公开答案，拉黑及解除不恢复旧参与资格，归档暂停新操作。


2026-10-03 第二阶段：长期社群增加空间介绍、开放／归档与活动预告。主办方明确发布预告、单独开现场、再明确关联邀请码；成员只预览元数据，入场及照片权限仍独立。归档保留历史阅读，阻止新的加入、发言、活动、招呼与投票，提交时核对空间版本。恢复开放和成员资格不代替本人同意。


「我的空间」在 `personal-space.js` 共用现有本人社群、现场和双向朋友读取接口；读取不创建成员或授予照片权限。列表读取失败收起旧内容，身份变化及屏蔽状态变化关闭私人视图。常驻导航和纸面回访中心提供短屏滚动与键盘焦点返回，完整实施范围见[完成清单](../../docs/event/PRODUCT-COMPLETION.md)。

当前入口 `/event-room/`。Node 24+ 提供同源页面与 API，配置持久存储；`runtime-preview/src` 与叠加式 drizzle 迁移是 Node/Worker 共享实现，发行包不能省略。

统一入场模块校验单一房间或社群邀请、同源精确路径与无额外参数的地址，拒绝跨站、混合目标、凭据、重复参数和片段。链接、二维码、NDEF 与原生 GATT UTF-8 值仅传递邀请网址；预览不创建成员或授予照片权限。原生应用权限和设备互通仍待实现验收。

现场、社群、照片、朋友和私聊各用独立授权。写操作使用幂等原请求，断网恢复不自动重发。衣橱明确保存后更新身份；个人纪念卡明确选择本人合法素材并预览实际成品。

共同创作共享实现 `event-corners.js` 与 `0010_event_corners.sql`。创作许可绑定好友关系及双方屏蔽代次，临时解除屏蔽或重新加友不能恢复旧许可。每人只修改本人贡献；引用本人照片与当前版本，不复制原件到公开目录。素材读取在对象返回后再次核对许可，保存事务同时校验内容版本与双向确认。

前端 `corner-panel.js` 保留按身份隔离的本地草稿和原请求。修改触发版本冲突复核并撤回旧确认，保存由每人独立选择。导出前后及下载前复核关系、素材、双方确认与当前本人保存版本，显示实际 PNG，关闭、切换身份、断网或权限变化时释放预览和照片 URL。长留言扩展画布，不截断全文。

流程为独立分支、草稿 PR、自审、必要测试与精确提交 CI、合并、预发布及实际下载验证。测试与发行证据不得冒充实机或用户研究；私人证据单独交付，不提交原件、凭据或本机标识。
