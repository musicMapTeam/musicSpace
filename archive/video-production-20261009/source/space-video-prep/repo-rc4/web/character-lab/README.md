# 单角色三维造型研究

`npm run build:character` 生成可离线打开的 `dist/character-lab/index.html`。

角色由定制闭合曲面、实体发束、弯曲五官与眼镜几何组成；不使用图片、面向相机的整张角色贴片或替换视图。脚底为 Y=0，正面为 +Z。转台采用真实 PerspectiveCamera 和 OrbitControls；固定观察角度沿圆弧过渡，避免从角色身体内部穿过。

`npm run test:character` 只验证有限位置、闭合边、正体积、非退化三角面及稳定部件分组，不验证美术贴合度或网格之间的穿插。每次修改仍需真实 GPU 正面、3/4、侧面、背面及转动检查。

第一次 GPU 四视图功能通过但美术未通过：后发厚壳、腿部线条伪影、肩袖及比例仍在修正。当前不扩展整套模板。
