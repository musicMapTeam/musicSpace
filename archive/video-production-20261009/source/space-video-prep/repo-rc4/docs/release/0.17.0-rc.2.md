# 0.17.0-rc.2 — 现场记忆与自愿参与

快速入场只需昵称与默认小人，换装可选。独处时提供邀请和首张照片；同场列表排除自己。照片默认私有，显式分享给本场与双方私下交换保持分开。可从共享照片找到作者、明确打招呼、双方接受后聊天，再从聊天回到当晚回顾。

参与选择按场次保存，默认为安静。安静用户仍能保存、分享和交换照片；新招呼要求双方当前选择愿意。改为安静会取消该场未接受招呼，现有好友和私聊保持。退出后不能改该场选择；重新以安静方式加入会取消旧待接受招呼。旧成员迁移为安静，并取消旧待接受招呼，不推断历史同意。

PATCH participation 使用成员权限、乐观 revision 和幂等操作键；SQL 提交时再次核验参与选择。取消编辑不提交；旧响应丢失后的重试读取当前服务端状态，不恢复历史 open。照片撤回、屏蔽、退出、交换撤销与备份恢复沿用原权限。

四个原 CI 失败逐项修复：Node/Worker 两个成员字段契约加入 participation 与 revision，仍严格限制字段且验证值域；招呼 UI fixture 显式提供双方 open，仍要求只有点击才发送；昵称标题更新，仍验证造型保留、精确返回预览、未同意加入，以及默认 quiet。没有删除行为断言。

运行包补入现有离线备份脚本与操作说明。独立 8790 使用合成数据，旧 8788 与用户数据不变。浏览器证据只含合成昵称、照片和消息。手机验收使用 Chromium 390×844 视口，不代表真实手机设备或目标用户研究。未新建公网服务、修改 gh-pages 或开展真实用户测试。

最终测试和浏览器结果在本次 PR 验证记录中列出；RC 只在最终 CI 通过并合并后由既有工作流发布。
