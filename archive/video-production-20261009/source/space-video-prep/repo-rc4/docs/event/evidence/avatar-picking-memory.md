# 小人命中缓冲与加载期修复

2026-10-01。位于 `web/event-room/illustrated-person.js`，不改角色 SVG、四个 480×1000 CanvasTexture、UV 取样方式、镜像、朝向、alpha > 88 的命中阈值或渲染分辨率。

- 命中检测只读透明度，不再为此保留四份完整 RGBA 数组。每人这部分 CPU 缓冲由 7,680,000 字节降为 1,920,000 字节，减少 75%；不等于整体内存或 GPU 占用减少 75%
- 独立 GC 检查确认临时 RGBA 数组/底层缓冲可在角色仍存活时释放；dispose 后 alpha 数组也可释放，即使测试仍保留旧采样回调
- 未取得可用贴图前隐藏人物平面，避免默认不透明白材质形成矩形；加载成功再显示。失败或已销毁后的迟到加载不会复活平面
- 81 项相关插画、实际 Three 结构/资源生命周期与新命中回归通过；覆盖 256 个 alpha 值、边界 UV、镜像射线、加载失败、迟到完成及回收。构建通过

这是源码与内存对象验证，没有新的 GPU 或实体手机帧率结论。正在本地验收的 event-loop v0 和视觉 v9 保持原字节，均尚不包含这项优化。
