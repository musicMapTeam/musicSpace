# 产品完成清单 · 2026-10-03

本轮从 0.18.0-rc.5 继续。负责人 Codex，唯一实施者；范围为长期音乐社群、认识音乐朋友与跨场次回访的完整产品旅程。有限三个实施阶段，逐段验收后继续，不增加积分营销、伪在线人数或伪音乐事实。

## 已具备

真实三维场馆与明确的二维手绘小人，本人身份与衣橱保存、明确入场及参与意愿、照片权限、双向交友和私聊、个人回顾、双人共同创作与署名 PNG；长期社群、散场聊天室、四张来源音乐关系卡、独立 Map 跳转、四个虚构专辑世界杯及邀请协议。

已有能力不是完整产品的证明：个人入口分散；长期社群缺乏介绍及完整场次组织页；音乐卡只有四张关系桥接，不是完整 Map 集成；世界杯固定四个虚构选项，主题、历史与讨论回路不足。

## 此次必须交付

### A · Done（候选验收）：统一个人空间及回访

- 进入后有常驻「我的空间」入口，不依赖当前参加某场现场。
- 本人署名与已保存小人贯穿个人主页；「我的社群 / 我的现场 / 好友与私聊 / 共同创作 / 身份恢复」在同一回访中心。
- 社群明确区分主持、已加入、已退出、被移除，现场明确区分进行、散场、离场，回访不自动加入或扩大照片权限。
- 刷新、跨标签、无房间、空列表、失败重试、键盘和短屏操作可达；旧身份丢失时立即收起私人内容。
- 多身份实际操作截图，必要测试、草稿 PR、自审与精确提交 CI。

候选证据：701 项适用测试、32 步主办方与普通观众浏览器旅程、五项构建、基础规则、AI 文件与角色结构检查通过。新身份空态、离场回访、好友私聊、社群、回顾、身份失效、读失败重试、键盘焦点及短屏操作均实际执行；正式发行按当前 PR / Release 记录登记。

### B · Doing：主办方长期空间与场次管理

- 主办方维护社群介绍与明确状态，管理成员及恢复资格；恢复仍需本人重新加入。
- 社群展示关联场次及进行/散场状态，主办方可从社群开始新场次并明确关联；成员只预览活动资料，另行同意加入现场。
- 清楚的主持权限、并发版本校验、归档或只读状态；保留历史内容与已有好友，不开放旧照片。
- 退出、移除、屏蔽及散场后可用性，持久化与恢复验收。

### C · Todo：持续音乐话题与内容组织

- 音乐探索明确区分已有四张核实关系卡、成员自填的未核实话题与独立 Map；不冒称完整地图数据整合。
- 成员明确创建音乐主题，分享与讨论可回到上下文，撤回与成员资格继续生效。
- 世界杯支持自建四项文字主题，标清成员提供的内容；不抓取封面、音频或歌词。保留当前虚构示例。
- 当前赛事、历史结果与明确的结果讨论入口形成闭环；真实票数、并发投票、显式平票决定仍保留，不做品味评分。
- 全量适用测试及多身份实包旅程覆盖身份恢复、共创撤销、社群不授旧照片、短屏和减少动态效果。必要 RC 实际下载、启动重启、逐文件校验。

## 外部条件与交付边界

真实观众理解、实体 iOS/Android、真实 BLE/NFC、原生构建签名与系统生命周期需要外部验收。本机已有工具能做的静态或编译检查会登记；不安装新许可工具，不创建凭据、不改系统权限、不写真实 NFC 标签。公网部署等待用户决定，旧 Pages 和 Map 部署保持原样。

更新既有服务前验证两库及其中照片对象的备份，使用原数据目录，保留其他旧实例。公开文档只记匿名产品事实；详细环境与截图保留在用户 Library。最终交付完整演示视频或清晰截图组、实际体验入口、已实现功能与未验证清单。
