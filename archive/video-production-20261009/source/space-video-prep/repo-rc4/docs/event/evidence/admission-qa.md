# 统一入场协议：软件验收结论

候选全量685项通过，最终协议及UI66项通过。31步浏览器检查覆盖完整邀请预览、取消、明确加入、重复点击、同身份多标签、混合链接拒绝、短屏、社群权限和重启持久化。

共享后端检查覆盖：预览不加入，未同意拒绝加入，新旧路由重复操作不重复加入，非作者不能读取私藏照片，关房后不得加入。加入现场不代表加入社群，也不授予好友或照片权限。

NFC标签入口只在符合条件的浏览器显示，需要主动选择操作；模拟UI检查覆盖重复点击和取消。原生适配源码未编译或签名，BLE/NFC设备互通、实体手机和真实观众仍待验证。软件结论不能替代这些外部验收。

本文件只记录匿名结论。详细截图及结果另向用户提供；实际发行包的核验完成前不把候选写成已发行。规则见[统一入场协议](../ADMISSION-PROTOCOL.md)。
