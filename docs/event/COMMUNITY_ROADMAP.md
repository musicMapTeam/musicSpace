# 音乐现场社群实施清单

负责人Codex，阶段分别提交独立PR，经测试、自审和CI后合并；只发布明确标记的预发布版本。保留同一真实三维场馆、可组合手绘二维小人、本人照片权限及双向好友，Music Map保持独立。

1. **Done：长期音乐社群与散场聊天室。** 明确加入、回复、未读、静音、退出及成员管理；长期社群与现场成员资格分别授权。参与意愿和自愿招呼一致，群聊不扩大照片权限。
2. **Done：音乐探索。** 允许列表公开音乐元数据、原创关系图和明确的独立Music Map跳转；歌曲卡署名、回复和撤回遵守消息权限。没有录音、歌词或未知许可素材。
3. **Done：专辑世界杯。** 四张明确虚构专辑，创建、二选一、真实票数、唯一投票、并发保护、公开平票决定及持久结果；不是品味评价或权威排行。
4. **Done：统一入场协议。** 链接、二维码、NDEF和原生GATT适配源码使用同一不含身份凭据的网址。先预览，再本人明确加入；近场连接是另外的主动选择。原生宿主、签名及BLE/NFC设备路径未验收，不声称已经实现手机间自动发现。见[协议与边界](ADMISSION-PROTOCOL.md)。
5. **Done：双人创作角。** 双方分别选择自己的小人、本人照片和留言，主动参与，编辑需要并发冲突处理；双方确认后各自显式保存。撤销、屏蔽或素材删除后不能继续读取或导出。

每阶段检查共享Node/Worker行为、幂等、权限、持久化、取消、断网重试、多标签及短屏，再核对实际发行包。个人身份的加密备份与明确恢复是独立选择，浏览器缓存不等于可永久找回身份。邀请码和近场信号不能证明身份、到场或照片许可。
