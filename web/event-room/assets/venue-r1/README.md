# Blender venue r2

Original static scenery authored with Blender by the project workflow, 2026-09-30. No third-party geometry, fonts or textures. 19,728 triangles, 12 drawing primitives, 8 materials; no external URI or decoder dependency.

`venue.glb` SHA256: `68f2b5991115dac38580e44f38277e9ca93be70d3bdf8e5806bbc64d59c85b8e`.

The editable `.blend`, original four offline renders, generator and validation script are retained in the Library asset package `libfile_fece4f9c808481918cc05e34b8c37996` version1. Reproduction scripts and coordinates are also retained under `docs/event/assets/`.

The browser loader maps authored linear base colors to the existing cel material factory. Dynamic 2D people, authorized photographs, photo frames, cameras and interaction state remain runtime-owned. Import success is exposed by `scene.venueAsset.status === 'ready'`; fallback must not be presented as the Blender venue.

Offline renders and geometry checks are not browser visual acceptance. Current integration awaits real GPU mobile/desktop camera, occlusion, material and interaction review.

The existing asset directory remains the stable integration slot. Revision r2 only re-parents the right PA and two gallery trims to MS_FOREGROUND_CUTAWAY; geometry, material colors and world transforms are unchanged. The photo reading camera hides this group and the overview restores it.
