# Music Space 实施说明 · 文档 3.1

当前入口 `/event-room/`。Node 24+ 提供同源页面与 API，配置持久存储；`runtime-preview/src` 与叠加式 drizzle 迁移是 Node/Worker 共享实现，发行包不能省略。

统一入场模块校验单一房间或社群邀请、同源精确路径与无额外参数的地址，拒绝跨站、混合目标、凭据、重复参数和片段。链接、二维码、NDEF 与原生 GATT UTF-8 值仅传递邀请网址；预览不创建成员或授予照片权限。原生应用权限和设备互通仍待实现验收。

现场、社群、照片、朋友和私聊各用独立授权。写操作使用幂等原请求，断网恢复不自动重发。衣橱明确保存后更新身份；个人纪念卡明确选择本人合法素材并预览实际成品。

共同创作共享实现 `event-corners.js` 与 `0010_event_corners.sql`。创作许可绑定好友关系及双方屏蔽代次，临时解除屏蔽或重新加友不能恢复旧许可。每人只修改本人贡献；引用本人照片与当前版本，不复制原件到公开目录。素材读取在对象返回后再次核对许可，保存事务同时校验内容版本与双向确认。

前端 `corner-panel.js` 保留按身份隔离的本地草稿和原请求。修改触发版本冲突复核并撤回旧确认，保存由每人独立选择。导出前后及下载前复核关系、素材、双方确认与当前本人保存版本，显示实际 PNG，关闭、切换身份、断网或权限变化时释放预览和照片 URL。长留言扩展画布，不截断全文。

流程为独立分支、草稿 PR、自审、必要测试与精确提交 CI、合并、预发布及实际下载验证。测试与发行证据不得冒充实机或用户研究；私人证据单独交付，不提交原件、凭据或本机标识。
