# 聊天室专辑世界杯 · 2026-10-02

基于明确加入的场次聊天室或长期社群。发起者确认标题后创建四张虚构专辑的两组首轮；专辑、乐队名称与原生CSS封面均为2026-10-02本轮创作，不含真实录音、第三方封面或听歌记录。按匿名身份每轮一票，不认证实体人或到场，不称音乐排行榜、权威评选、用户品味评分。

选一张只打开确认，取消不投；勾选后提交，投后不改。数据库主键(match_id,user_id)、成员/屏蔽守卫与事务确保不同键并发只一票；同键重试返回原结果。新票与晋级并发时重新核对两边总数，旧总数不能落成结果。两个首轮并发结束也只生成一个决赛。

发起者需仍可参与才能明确结束本轮。零票不晋级，非平票按真实票数决定；平票须发起者明确选择和留下理由，结果标明发起者决定，不伪装成票数胜出。晋级冻结当时总数，结果/理由保留。发起者退出或被移除时不能晋级，界面说明暂停并等待重新获得资格，不替成员投票。成员可不投。

读取、投票、晋级均需当前聊天室成员；房间聊天室另需有效现场成员，长期社群与现场独立。屏蔽任一方向后不读取对方发起的杯赛；逐人投票只向本人返回，其他人只看总数。离开/移除不清除已明确计入的历史票数。场次结束停止入场/照片上传，不清除已加入聊天室的世界杯；离场则失去对应房间聊天室资格。不得据此扩大照片或好友权限。

UI与当前场馆、纸签和小人共用。列表最多20个杯赛；每身份每天最多发起3次，适用于小型聊天室，不代表大规模运营完成。断网请求记入music-space-worldcup-operation:v1前缀的本机待确认日志，手动原键重试、不自动再投；关闭只停止等待，不承诺撤销已到达的投票。新身份不能带回旧身份投票。

共享实现runtime-preview/src/event-worldcup.js、worldcup-albums.js及叠加0009；drizzle、Node、Worker与运行包一致。结果仅当前聊天室可读，讨论回已有聊天室，不自动公开到其他社群或照片墙。
