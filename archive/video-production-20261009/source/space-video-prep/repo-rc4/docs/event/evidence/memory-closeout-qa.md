## 源码与检查

- `memory-card.js` 只接受当前身份、当前回顾页的本人照片；明确确认，最多两张；重新读取、图片解码后再次核对；取消、重复点击与失败重试。
- `memory-card-png.js` 使用已批准小人 SVG 与已授权本人照片 Blob；没有名单、私聊或别人图片。下载属于本地副本，不改分享权限；成品 URL 关闭/下一次生成时释放。
- `app.js` 接入回顾/成品预览、原图读取失败与定向重试；较晚的重新核对回调不能覆盖后来的页面或选择。
- `event-memory-card.test.js` 与 UI binding 检查涵盖显式同意、陌生作者、过期/跨身份回顾、无图票、删除/小人变更/切场次竞态、取消、重复点击与读取失败。最终本机完整回归 655/655 通过，0 失败/跳过；相关独立 UI/导出检查 67/67 通过。准确 HEAD 的 CI 和发布检查另记。
- 五入口构建、AI 完整性、旧版规则/API 与角色几何检查分别运行；Node/Worker、权限、幂等、持久化与备份检查没有被省略。
