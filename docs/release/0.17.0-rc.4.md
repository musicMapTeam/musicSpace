# Music Space 0.17.0-rc.4

这一轮收尾把「这一晚」接成可带走的个人成果。回顾里明确选取最多两张当前页的本人照片、可选本人已保存小人，确认后下载 1080×1440 PNG，保留摄影与留存署名。也可不选照片，保存文字纪念票。页面展示真实成品并允许再次下载。

纪念卡不收他人的照片、交换照片、好友名单或私聊，不上传或自动公开。读取照片与渲染后再次核对身份、场次和照片版本；素材被删除、身份/造型改变或断网时不会输出不完整图片。关闭/返回取消待处理导出，重复点击只产生一个下载；已下载副本无法召回，分享前由用户确认愿意公开内容。

统一既有场馆、手绘二维小人、照片、私聊与回顾的暖纸、墨色和植物绿纸签语言。照片读取失败有明确说明与原图重试，恢复连接后重新核对。保留现有三维场馆与合法资产，没有重建素材、外部 AI 或新增运行依赖。

本机最终 655/655 回归、五入口构建、AI/基础 API/角色检查通过，35 步双身份真实 Intel GPU 浏览器及同 DATA_DIR 正常服务重启通过。实际浏览器范围见 [验收记录](../event/evidence/memory-closeout-qa.md)。手机检查是 Chromium 视口，不能代替实体手机、微信、大陆网络或真实观众研究。

此版本是预发布运行包，入口 /event-room/，Node 24+ 同源 API 与持久 DATA_DIR。runtime-preview/src 与 drizzle 随包提供。没有部署公网，没有更新旧 gh-pages 或 Music Map。实际发布和下载包校验由交付记录确认，不把候选构建写成生产上线。
