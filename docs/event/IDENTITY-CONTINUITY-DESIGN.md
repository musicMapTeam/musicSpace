# 身份连续性 · 仅设计与合成数据检查

2026-10-01。当前可玩版本仍依赖本浏览器中的匿名身份。没有备份且清除了浏览器数据，就不能凭昵称找回原身份；房间邀请码也不是身份凭据。

本轮不接真实凭据导出、导入、密码输入或身份替换 UI。`web/event-client/identity-backup.js` 是未被页面引用的纯本地实验辅助函数：不读取浏览器存储、不联网、不写文件、不安装身份。测试只使用明确合成的 token。

## 后续候选路径

用户在原身份仍有效时主动制作加密备份，用于另一浏览器恢复同一个服务里的既有身份。它是提前备份/设备迁移方案，不能解决“凭据和备份都已丢失”的账号找回。数据服务本身被删除时，备份也不能重建照片或私聊。

原服务 origin 只是必要条件，不是完整可信证明。后续接入前还必须：

- 用户明确允许导出这份既有身份材料；恢复须明确同意替换当前浏览器身份，不能自动发生
- 对备份中的精确账号向同一服务进行认证核对；读取服务端当前资料版本，不能用旧头像/旧 revision 覆盖新资料
- 检查凭据过期、撤销和服务数据存在性，拒绝认证失败；不把“能解密”当作服务仍认可身份
- 限文件尺寸、格式、算法参数、加密输入；错误密码和篡改失败不改变现有会话
- 来源信息也参与认证加密。篡改来源后不能把解出的凭据传给另一个地址；不能自动跟随重定向
- 替换时立即清理旧私密 DOM、图片 URL、读取与待发视图；旧身份冻结操作不转发给新身份，迟到结果不能写回旧 token
- 不上传备份到 Library、云存储、日志或外部服务；不代用户保存备份密码。进入真实凭据操作前另行取得所需授权

## 当前合成检查的边界

本地辅助函数使用浏览器原生 Web Crypto，PBKDF2-HMAC-SHA-256（600,000 次）派生 AES-GCM-256，随机16字节 salt、12字节 nonce 和128位认证标签；身份与来源绑定。这里的参数选择不是安全审计或合规认证。[Web Crypto 标准](https://www.w3.org/TR/2017/REC-WebCryptoAPI-20170126/#aes-gcm) 描述其加密接口与附加认证数据；[OWASP 的 PBKDF2 参数建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#pbkdf2) 为迭代成本提供参考。

合成单元检查已覆盖正确解密、随机输出、错密码、密文/来源篡改、来源不符先拒绝、尺寸和参数上限。没有真实用户凭据，也未做浏览器恢复、密码体验、设备迁移或安全审计。本轮继续优先交换和房主管理的实际可玩闭环。
