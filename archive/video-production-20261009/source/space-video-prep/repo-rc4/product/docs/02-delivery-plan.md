2026-10-03 第三阶段：成员音乐话题可发布、署名、撤回并明确带回讨论；Worldcup 支持四个自填文字选项、真实票数、明确平票理由、历史结果与讨论。新增自愿「音乐默契局」和轮流「关系接龙」：至少两人明确参加，选择揭晓前保密，接龙区分已核实共同音乐人与成员自述。没有评分、自动好友或自动邀请；退出清理未公开答案，拉黑及解除不恢复旧参与资格，归档暂停新操作。


2026-10-03 第二阶段：长期社群增加空间介绍、开放／归档与活动预告。主办方明确发布预告、单独开现场、再明确关联邀请码；成员只预览元数据，入场及照片权限仍独立。归档保留历史阅读，阻止新的加入、发言、活动、招呼与投票，提交时核对空间版本。恢复开放和成员资格不代替本人同意。


新一轮分三个有限阶段：个人空间回访、长期社群及场次管理、音乐主题及结果讨论。首阶段 0.19.0-rc.1 候选的 701 项测试、32 步实际浏览器旅程及五项构建通过；第二阶段经 PR15 与 0.19.0-rc.2 交付；第三阶段候选包含音乐主题、Worldcup 与自愿小游戏。每段独立草稿 PR 与验收，最终实包及演示完成后停止。

交付独立 Music Space。Music Map 和旧公开演示保持原样，本轮不部署网站、不提交比赛，也不使用新的素材、账号、服务或凭据。仅发布明确标注的预发布版本，不声称正式生产上线。

现场入场、参与意愿、手绘小人装扮、照片权限、双向交换、好友私聊与个人纪念卡已实现。长期社群、散场聊天室、音乐探索、虚构专辑世界杯和统一入场协议分别经独立 PR 交付。

当前共同创作候选包括：双方本人参与、本人素材选择、版本冲突处理、双向确认、独立保存、实际署名 PNG、撤销与关系失效。候选全量 699 项测试通过。自审、精确提交 CI 和浏览器闭环通过后才合并；必要预发布须实际下载，并检查运行文件一致性与保存后重启。

验收使用合成身份和本人合成测试照片，不发布私人照片或冒充真实观众。浏览器手机尺寸检查不等于实体手机；真实手机、真实观众、原生应用构建签名以及 BLE/NFC 设备和系统权限、取消、后台行为仍需外部验收。

正式比赛视频须含实际页面操作与讲解或字幕；参赛作品选择及提交由团队决定，不替队友表态，也不推算获奖概率。
