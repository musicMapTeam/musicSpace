# Music Space 0.20.0-rc.1 — 刊物夜场与应用内音乐关系探索预发布

基线 0.19.0-rc.4。真实三维 Livehouse 保持既有几何体积，采用暖木、深绿与暖纸的统一刊物语言；二维手绘小人、照片、本人空间和小游戏共同构图。聊天室消息独立滚动，发送区常驻，管理操作收进菜单。

应用内 Music Map 复用独立版本已留档的 29 位真实音乐人、37 条共同演唱录音关系。支持音乐人选择、关系详情、录音版本/署名/出处、返回上一个发现、完整图和目录内路径。图内拖动、按钮缩放；图外滚动页面。打开不发布内容；明确选择音乐发现后准备聊天室分享草稿或关系接龙起点，仍须本人确认。独立 Map、旧 Pages 和原照片权限保持原样。

这是预发布，不代表正式生产上线、真实手机或真实观众验收。无新外部素材、音频服务、账号、凭证或公网部署。具体构建、浏览器、实际包及原数据升级验证以 README 和当前项目状态的本轮记录为准。
