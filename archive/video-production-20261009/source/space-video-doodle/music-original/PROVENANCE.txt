Same Moment, Other Side -- original score for the Music Space competition video (doodle cut)
=========================================================================================

What it is
  Instrumental, 124 BPM, 4/4, 176.000 s (2:56), D major with the final chorus in E major.
  Every sound is computed by the Python code in src/ (numpy + scipy): modal plucked-string models
  (electric, acoustic, palm-muted and clean guitars, pick bass), a sine whistle with breath noise,
  a modal glockenspiel, an FM bell, an additive combo organ, an additive synth pluck, a PolyBLEP pad,
  and drums/percussion built from sine sweeps, metallic partials and filtered noise.
  No samples, no loops, no recordings, no third-party audio, no voices or lyrics, no AI music generator.
  Melodies, arrangement and sound design were written for this project.  The chord progressions are
  common pop progressions (I-V-vi-IV, I-vi-IV-V, IV-V-iii-vi, bVI-bVII-I), which are not anyone's property.

How it was made (deterministic: the same code gives the same audio)
  /tmp/space-video-prep/tools/venv/bin/python src/score.py    # render (~45-90 s): out/*_float.wav, out/beats.json
  /tmp/space-video-prep/tools/venv/bin/python src/analyze.py out   # measurements -> analysis/report.json
  /tmp/space-video-prep/tools/venv/bin/python src/export.py   # 48 kHz/24-bit WAV, AAC m4a, stems, preview, PNGs, beats.json
  node src/map.mjs                                            # png/arrangement-map.png
  Optional SCORE_CONFIG=<json> changes section lengths / the AI chime position (see the header of src/score.py).
  Tools: Python 3.14.3, numpy 2.5.3, scipy 1.18.1; ffmpeg (Homebrew) only for format conversion;
  Apple AudioToolbox AAC encoder (aac_at, 256 kb/s) for the m4a.  The fonts in the PNG map are the
  product's own OFL fonts (/tmp/music-space-font-cache); they are not part of the audio.
