# Music Map 原版页面

来源为 `musicMapTeam/musicMap` 的 `c626c0e54de1f5ea362710f1e47bacd8c09aa804`（0.16.0）。保持原版小院、唱片桌、翻片寻声、自由探索、作品署名与「我的发现」，不是上一轮的 SVG 简化图。

0.21 接入时的适配只涉及 Space 入口与返回草稿、独立存储前缀、页面销毁、共享 Three 模块和发布构建；2026-10-07 起的改版见下一节。原版第三方许可随源码与构建保留（Phosphor 图标除外，见下一节「图标」一条）。开放目录是来源记录里的作品署名，不冒充核实过的共同演唱；只有既有 37 条核对录音能准备聊天室与接龙草稿，发送和开局仍需本人确认、服务重新核对权限。

入口 `/music-map/`，从 `/event-room/` 进入。完整页面导航卸载前一个场景，不把两个 Three 渲染器叠在同页。返回位置与待选歌曲只放当前标签页的 `music-space-map-return:v1`；探索与收藏分别用 `music-space-map-exploration:v1`、`music-space-map-saved-music:v1`，不读取或改写独立 Map 的存储键。

## 2026-10-07 音乐探索：手绘涂鸦风与完整产品文案

2026-10-07 起，这个页面保留下来，并入 Music Space 的整体风格：界面叫「音乐探索」（Music Space 字标加「音乐探索」贴纸），手绘涂鸦风（规范见 `docs/design/doodle.md`），去掉说明性文字，每条连线的出处收进「来源」按钮。

- 样式：`css/legacy.css` 把 0.16 的 21 个样式表原样放进 `@layer legacy`，只保留布局（场景旁的位置、手机与平板断点、吸底条、触控下限、无 WebGL 的页面流）；`css/doodle/` 不分层、最后导入，按区域重画外观（`bridge` 把旧变量指向 `tokens.css`，`controls`、`shell`、`home`、`shop`、`tags`、`papers`、`records`、`fallback`）。颜色只来自事件房间的 `web/event-room/doodle/tokens.css`，样式表里没有新的十六进制颜色；`type.css` 和 `kit.css` 也直接共用。`index.html` 的 `data-look="doodle"` 是给三维场景的开关。场景的工具条容器保留一层看不见的渐变背景，`sakura-framing.js` 才会把它算作障碍物。
- 字体：用事件房间自托管的 Doodle 字体，由构建在 `<head>` 里加链接，不从代码导入（单文件页面会把约 2.4 MB 的 woff2 内联进去）。Pages 构建（`vite.static-map.config.js`）链接 `../fonts/doodle/`，`/musicSpace/` 和 `/musicSpace/preview/` 都适用；Node 构建（`vite.map.config.js`）链接 `../event-room/fonts/doodle/`。两者都预加载 `marker-0`、`display-0`。
- 「来源」：`map.js` 的 `sourcesHTML()` 是一个原生 `details/summary`，按顺序列出演唱出处（链接、依据原文、访问日期）、其余署名出处及各自支持的署名、QQ 音乐同一录音的页面或没有链接的原因、署名范围一句。寻声进行中只列演唱出处和 QQ 音乐一项，并且不出现两位歌手以外的名字。用在共同演唱、作品署名、TA 的歌、TA 的合唱、连线歌单、走过的路和「留下的歌」；手牌上的「来源」按钮打开共同演唱并展开来源。版本行里只记录未完成核对的括注留在「来源」里（`shownLabel()`），数据不变。
- 数据来源：关于页的「数据来源」一节列出合唱目录、QQ 音乐链接、开放曲库（数据集、快照、许可标注）、字体和代码的来源与许可，数字从数据现算；开放曲库页脚的「数据来源」直接打开这一节。
- 0.15 的虚构示例目录（虚构歌手、歌曲与策展标签）已删除；存储里如果还有指向它的记录，`prepareStoredMap()` 会丢掉。
- 图标是自绘的线条图标（`icons.js`，沿用原来的名字），不含 Phosphor 的路径数据，所以两套构建不再附 Phosphor 的许可（`assets/licenses/phosphor-*` 只留作被替换图标的出处记录，不发布）；分享 PNG 改为纸面涂鸦，颜色在绘制时从页面的 tokens 读取，先按图上的文字加载字体切片再画。
- 三维：进到店里（唱片桌和「我的发现」）屋顶整体收起，招牌和遮阳篷一起收：手机和竖放平板的「我的发现」镜头离柜子较远，招牌留着就正好落在顶部标题栏后面。唱片桌镜头不画门前的灯串（离镜头太近，会印成一道粗墨线），小院和「我的发现」照常有。高度不超过 600px 的手机，小院纸片收起底部三个链接（「我的发现」在底栏，「留下的歌」在它里面，「开放曲库」在唱片店的「目录」里），给小院留出高度。
- 唱片桌上的 − 全图 + 是一条纸胶囊，宽度和 0.16 的一样（约 140px）：底部的纸和手牌两侧各留 200px 并带 8px 硬阴影，更宽的工具条会滑到它们下面。平板（761–820px）的「本次发现」去掉「本次」，900px 以下去掉书签图标；380px 以下的手机把「返回上一位 / 回到起点」印成「上一位 / 起点」（按钮的无障碍名称不变）。
- 「留下的歌」里真实合唱的「来源」和「去 QQ 音乐听」并排，不藏在折叠行里；能展开的行（日期、专辑、数据集行号）右侧有箭头。
- 测试：`tests/original-map-copy.test.js`（界面文案、虚构目录、数据来源、样式分层、无新色值、两套构建的字体链接）、`tests/original-map-sources.test.js`（37 首的「来源」完整、寻声中不越界）。
