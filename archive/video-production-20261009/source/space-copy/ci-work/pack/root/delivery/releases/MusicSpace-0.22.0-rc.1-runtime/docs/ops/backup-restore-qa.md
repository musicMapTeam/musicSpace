审查边界：这是停服后完整目录备份，不提供在线热备，也不探测/终止业务进程。操作者需停掉所有写入实例，不能把 `--service-stopped` 当成自动停服。验证只打开本次新建副本；采用分块复制/哈希，避免将整个照片数据库载入内存。备份完成标记在全部核验通过后写入；SHA256 仅防损坏，不替代来源信任、存储访问控制或加密。
