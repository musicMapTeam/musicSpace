# 0.19.0-rc.3 — 音乐话题与自愿小游戏候选

在同一纸面夜场语言中，成员可分享署名音乐话题、撤回引用、发起四个自填文字选项的 Worldcup、回看完成结果并明确回到聊天室讨论。默认四张原创专辑仍标明虚构，自填音乐资料标明未核实，不抓取封面、音频或歌词。

「音乐默契局」至少两人自愿参加，答案揭晓前保密，仅在主持明确揭晓后显示真实合计和共同选择；不同选择照实显示，不强行选优胜者。「关系接龙」每轮本人作答，既有已核实共同音乐人与成员自己的联想分开署名。主持人可注明原因跳过、继续或明确取消。退出删除未揭晓答案，人数不足或没有完整结果时不虚构结束成果。

原请求可断网恢复，单轮答案唯一，多标签不能重复或修改；拉黑解除不复活旧参与资格。话题撤回隐藏引用，归档保留历史并暂停新操作。原照片和好友权限没有扩大，不自动邀请或公开私人资料。

本轮三阶段完成后停止扩展。精确提交 CI、实包下载／启动／重启及数据保护证据按最终交付记录核对。预发布不代表正式生产上线；实际手机、真实观众、BLE／NFC 和原生应用编译签名仍未验收。旧 Pages 和 Music Map 保持原样。
