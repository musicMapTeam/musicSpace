# 快速入场与「这一晚」回顾 · 本地候选

2026-10-01。范围是昵称快速建立身份、明确同意入场、按真实场次回顾照片/当前朋友、继续真实场次或输入新邀请码。没有添加虚构活动、外部推送、找回凭据、付费服务或公开部署。

## 实现

- 新身份先填昵称，可使用当前默认小人；随时主动打开部件衣橱。保存身份不会自动勾选或提交入场同意。取消换装回到昵称页，入场后继续逐件换装
- 创建/加入已提交成功但房间读取失败时，明确显示「入场已确认」，只重读返回的原 roomId，不重复建立身份或房间
- 新只读接口 `GET /api/event/rooms/:id/recap`。历史参与者可读场次资料；他人照片仍要求双方当前成员、明确成员分享、未删除及双方未屏蔽；离场后只读自己的未删除照片。当前双向朋友按 pair.room_id 属于此场且仍 accepted 筛选，不冒称完整历史结识记录
- 照片和朋友分别每页 24 条，支持两个明确 UUID 游标，同一次事务快照返回两页。翻页替换，不无限合并旧快照。照片字节仍由原权限接口再次核验
- 客户端 recap 与当前房间/三维成员/邀请地址分开；独立请求和身份代次保护，关闭/换页/切身份拒绝旧响应和旧图片。同页刷新不反复取消慢图片；图片被收回时旧完成仍被拒绝
- 「我的现场」与离场/结束后的入口能回看同一场；回顾可打开当前朋友的既有私聊，再选择真实邀请码、开一场或已有场次。已离场的开放场次重新预览和同意；关闭场次只回看
- 网络未确认时标为上次读取记录，不假称最新。撤回、删除、屏蔽和关系变化在当前页重读与已确认本地操作中清理

## 仍未验证

该 240 项不是浏览器屏幕验收。原 Windows 实测通道暂时出现 executor capability 查询故障；补充的云 Chromium 访问本机地址被 `ERR_BLOCKED_BY_CLIENT` 拦截，未绕过。测试自有本机服务已停止。
