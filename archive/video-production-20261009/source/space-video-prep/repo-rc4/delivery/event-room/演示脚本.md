# 两分钟真实操作演示

这是录制顺序，不是已经录制的视频。使用两个独立浏览器的合成身份，保存不同的部件搭配，其中一位不戴眼镜；场次使用「原创示例·返场夜」，照片使用包内有来源说明的虚构演出素材。

| 段落 | 实际操作 | 屏幕文案建议 |
| --- | --- | --- |
| 0–20秒 | 主办方开一间现场；另一身份打开邀请、本人确认加入；切回全景看到双方 | 一场音乐，把我们带到一起 |
| 20–35秒 | 衣橱只换一件上衣或发型，实时预览，再明确保存；另一身份看到新造型 | 小人是我，每一件都能自己搭 |
| 35–70秒 | 两人各保存照片；A选定自己的图申请交换B的视角；切到B核对两张图、明确接受；再打开确切原图 | 把我拍到的，换成你看到的 |
| 70–95秒 | A打招呼，B本人接受，A发送文字，B实际打开看到 | 愿意认识，才继续聊 |
| 95–115秒 | 离场后打开这一晚回顾；展示个人照片、有效联系与仍获授权的交换 | 音乐散场，相遇留下 |
| 115–125秒 | 打开真实下一场邀请码入口，或回到可创建场次的入口 | 下一场，再见 |

如果要展示房主管理，另录短片：提交反馈、具名确认移出、恢复申请资格、对方本人重新同意。不要把打开确认框或取消操作剪成已经完成。

可以剪去等待，但不能伪造参与者、接受动作或聊天，不把接口返回当实际界面点击。全部参与者须标注为演示身份。只用有权使用的声音；无音乐时保留操作声或静音即可。录制和预览不是比赛提交。
