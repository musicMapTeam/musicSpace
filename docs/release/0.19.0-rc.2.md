# 0.19.0-rc.2 · 长期空间与活动候选

社群不只是一间聊天室：主办方可以维护介绍、明确开放或归档，发布下一次活动预告，再单独创建并确认关联本人现场。成员先预览活动，仍需本人同意入场；社群身份不授予旧照片权限。

归档保留历史阅读、既有好友和个人回顾，阻止新的加入、发言、活动和投票。空间版本在提交时再次核对，归档后重新开放不会复活此前排队的写入。活动发布与修改保留原请求用于断网恢复，明确取消预告不删除现场或回顾。

本候选完成第二阶段；自建音乐主题、Worldcup 选项和结果讨论仍在最后阶段。原生编译签名、真实手机、真实观众及 BLE/NFC 设备仍待外部验证。预发布不代表正式生产上线，不改旧 Pages 或 Music Map。
