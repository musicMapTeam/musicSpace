# 刊物夜场与应用内 Music Map 验收

本轮以 0.19.0-rc.4 为基线，范围为真实场馆的运行时调色、二维角色与纸面界面，以及独立 Map 已留档数据的应用内复用。独立 Map 仓库、公开旧版和旧 Pages 没有更新。

## 已执行

- 本机 Chromium 实际 WebGL2 渲染，桌面、390×844 和 320×568；二维手绘人物与三维场馆分别报告。无 WebGL 的单独降级用例仍能浏览公共音乐目录。
- 应用内 Map 13 步：三身份明确入场、聊天输入留在可见区域、37 条目录的节点与来源、明确分享及另一身份读取、29 节点全图、准备接龙而不自动发起、返回草稿与镜头、短屏、独立拖动/缩放、断网读取禁用发送并保留草稿、本人明确刷新后恢复、无 WebGL 降级。个人旅程另覆盖断网写入的原请求重试。
- 音乐互动 19 步：本人自愿加入、四个原创虚构选项、未揭晓答案保密、多标签重复提交、实际合计、已核实音乐人与明确的个人自述接龙、作者撤回、短屏、退出、跳过、结束和正常重启。轮次使用服务端从 1 开始的编号。
- 个人空间 32 步：长期社群邀请与本人同意、散场继续讨论、回复、静音、离线重试、第二标签撤权、恢复资格后重新选择、双方接受后的私聊、加密身份备份与错误密码保护、正常重启、个人回顾入口、空态、失败重试、键盘返回和身份失效清理。

以上使用相互独立的合成身份与隔离数据目录；不是真实用户研究或实体手机验收。测试曾发现菜单路径、邀请码读取、异步权限变化及解除网络拦截的等待需要更新，保留失败记录后通过真实可见菜单重新操作；没有强制点击隐藏或禁用按钮。RC.1 实包发现的 320×568 操作／导航重叠已通过 PR20 修复，最终 RC.2 的共同记忆 15 步包含实际 PNG、删除原图与任一方撤回后的双端导出失效。主办方 16 步、自填 Worldcup 15 步、统一入场 10 步亦在最终实包通过。

## 最终交付证据

- PR19／PR20 均经过草稿、自审和精确提交 CI 后合并。最终 [RC.2](https://github.com/musicMapTeam/musicSpace/releases/tag/v0.20.0-rc.2) 运行提交 `ce4f2e93358bfa6e729a9da0a6546db9db16a3bf`，717 项适用测试、五项构建、AI／角色检查及 Docker 通过。
- 官方工作流产物经当前 Library 正规传输下载，里面的运行压缩包与 Release 公布的 SHA-256、字节数一致；72 个运行文件逐项匹配已验收构建。七条最终实包旅程共 120 步通过，浏览器脚本错误为 0。
- 原本地服务在环境恢复时已停止，未强制终止旧进程。两库完整性与新备份、全部原业务行和 16 个私人照片对象核对后恢复，正常 SIGINT 与重启后再核对业务和照片。匿名请求不获得私人音乐 API；实际页面与运行包逐字节一致。过期速率窗口的既有清理独立记录，没有排除任何用户业务表。
- 最终运行包、八张重点实包截图及包含 433 张各阶段截图／失败诊断的证据 ZIP 已保存用户 Library，真实 ID 随交付返回。没有上传数据库、私人照片或身份恢复文件。

## 数据与权限

真实音乐数据取自独立 Map 的 `c626c0e54de1f5ea362710f1e47bacd8c09aa804`：29 位音乐人、37 条演唱录音边，保留录音版本、署名、证据、检查日期和来源。目录最短链只代表该目录，不表示所有音乐史关系。没有音频、封面或歌词；不将开放元数据当作关系核实结果。

音乐分享沿用聊天室成员资格、明确确认、幂等、撤回、引用失效和屏蔽规则，Node 与 Worker 共用允许目录。打开 Map 不创建身份或发布内容；准备接龙也不代替最终确认。照片、回顾与共同创作仍使用既有合法素材选择及导出检查，不扩大私人照片权限。

## 未验证

实体 iOS／Android、真实观众、美术与可读性反馈仍待外部验收；BLE／NFC 及原生应用编译签名不在本轮。此版本是预发布与本地预览，不是正式生产上线；旧 Pages 与独立 Map 保持原样。
