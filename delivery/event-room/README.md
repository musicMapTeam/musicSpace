# Music Space · 本地体验版

在同一个音乐现场，带着自己的小人入场，交换彼此的照片，再决定要不要认识。

这是一份能独立运行的本地原型：真实三维 Livehouse、分层手绘小人、实时自由换装，连接本机的房间、照片和私聊服务。原件、分享和认识都由本人选择。

## 打开它

需要本机已有 **Node.js 24 或更新版本**。解压完整文件夹，Windows 双击 `START-WINDOWS.cmd`；Mac/Linux 在该文件夹执行 `sh START-MAC-LINUX.sh`。无需安装项目依赖，也不需要联网。

启动后打开终端显示的完整地址，保留终端窗口。结束时按 Ctrl+C。第一次会选择可用的本机端口，之后保留同一个地址；已有端口被占用会明确退出，不会关闭其他服务或偷偷换地址。

保留运行后生成的 `data` 目录和浏览器存储，才能继续使用当前身份和记录。清除浏览器存储会失去匿名身份，昵称不能找回它。更新版本时先关闭旧页面，保留数据和原地址，再打开新页面。

## 先走一场完整体验

1. A 从「我是主办方，开个房」开始，留一个昵称，创建「原创示例·返场夜」。确认愿意向同场成员展示昵称和小人后入场；换装可以稍后再做
2. 在另一个浏览器或隐私窗口打开邀请，创建 B，核对场次并本人勾选加入。两个窗口必须使用独立存储；同一浏览器的普通标签共享身份
3. 打开「我的小人」，逐件换发型、眼镜、上下装、鞋或配饰，一边换一边看。取消会回到原造型；明确保存后，另一窗口才能看见变化。眼镜可以选择「不戴眼镜」
4. 两人各选择一张包内示例图。照片可以仅自己保存，也可主动分享到本场。点照片墙中的图，查看确切作者和照片
5. A 打开 B 的照片，选择「用我的照片，交换这个视角」，选定自己的图并确认。B 会看到限尺寸预览，明确接受这两张图后，双方才获得对应原图的交换访问权
6. 点另一个小人靠近，打个招呼。对方明确接受成为朋友后才能文字私聊。服务确认保存与对方实际查看是不同状态
7. 两人离场后，打开「我的现场 / 照片」回顾这一晚：自己的照片、目前仍有效的联系，以及独立的照片交换。可以输入另一个真实邀请码，或开下一场

衣橱以部件选择为主。共有 8 种发型、6 种眼镜状态、6 种上装、6 种下装、4 种鞋、6 种配饰状态，合计 36 个装扮选项；「无眼镜」「无配饰」包含在对应数量中。另有表情、姿态和配色。折叠的组合示例只是快捷试穿，选定后仍能分别编辑每一件。

## 照片、认识和现场管理

- 照片默认仅自己保存。上墙、定向交换和成为朋友是各自独立的选择；房主也不能读取成员私藏或私聊
- 交换指向两张确定的照片和两个人。接受后散场仍能访问；任一方撤销，会结束双方这次交换的在线访问，双方原件保留。已经下载的副本无法收回
- 从墙上收回照片，只结束墙上分享；「收回这张照片的全部分享」还会结束相关交换。屏蔽会结束两人之间的交换，取消屏蔽不会自动恢复
- 双方接受联系且未屏蔽时才能发送新私聊。移除朋友或屏蔽后，既往文字保留，不能继续发送；不会显示对方后来更新的资料或新的已读状态。文字存于本机服务，不提供端到端加密
- 向本场房主反馈，需要确认具体目标和本人填写的说明。不会自动附上私聊或照片副本；房主不收到举报人的身份字段，但文字本身仍可能让人认出作者。这里没有独立平台审核团队
- 房主可以具名确认移出某个身份，并允许其重新申请。恢复资格不会自动入场，对方仍要亲自同意；旧照片墙分享与待回应交换不会自动恢复

## 断线时

「已由服务保存」表示服务已确认；断线或回应丢失时，使用原操作重试，保留原内容和目标。完整拒绝与结果未知会分别显示。未确认的移出须先处理原操作，再恢复申请资格。

同一浏览器的普通标签共享一个匿名身份。身份在另一标签发生变化时，页面会清理旧私密内容并重新加载核验。尚未提交的选图是当前设备草稿，同时编辑同一份草稿不会自动合并。

## 演示范围

本包只监听 `127.0.0.1`。邀请用于这台电脑上的独立浏览器，没有开放到手机或公网。不要分享运行后产生的 `data` 目录。

场馆是原创 Blender 模型，由 Three.js 在真实空间里渲染；人物是随镜头选取朝向的二维分层立绘。人物近景聚焦选中者，照片墙机位暂时隐藏挡住内容的道具，返回全景后恢复。名单与实际人数保持一致。

`sample-photos` 中的 AI 舞台和人群图片是原创虚构演出素材，不是真实摄影；程序测试图也有明确标注。所有示例都要主动选择和保存，不会自动上传。房间声景为原创示例，不代表真实演出曲目。

关键流程已经用真实本机服务、多个独立合成身份与桌面 GPU 浏览器验证。**这份具体版本的通过范围和未验项，请看「版本说明.md」**。源码测试、桌面手机尺寸视窗和实体手机是不同范围。尚未完成身份丢失找回、新版公网运行、实体双手机/移动网络验证、生产负载与完整安全评估，也没有以真实观众研究证明留存效果。
